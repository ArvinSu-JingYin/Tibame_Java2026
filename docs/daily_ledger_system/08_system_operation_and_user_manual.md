## 第 1 章：系統概述與環境準備

### 1.1 系統特性與離線說明
- **Strict No-CDN (純離線架構)**：所有前端套件（Bootstrap 5.3、Vue 3、Axios、SweetAlert2）均由後端本地靜態資源目錄託管，在完全隔離無外網（Air-Gapped）環境下依然能 100% 穩定秒開。
- **瑞士國際美學**：直角銳利邊框 (`border-radius: 0px`)、極簡幾何網格、瑞士經典紅色標示 (`#DC2626`) 與無襯線高對比排版。
- **資料嚴格隔離**：後端透過無狀態 JWT Token 與 `CurrentUserContext` (ThreadLocal)，確保每位使用者僅能讀取與異動專屬於自己的帳目與自訂分類。

### 1.2 系統存取路徑
啟動系統後（可透過 `./start.ps1` 一鍵智能啟動），以現代瀏覽器（Google Chrome、Microsoft Edge、Mozilla Firefox 等）訪問以下入口：
- **登入/註冊入口**：`http://localhost:8080/login`
- **記帳主工作台**：`http://localhost:8080/ledger`（未帶 Token 存取時將自動導向至登入頁）

### 2.1 帳號註冊流程
1. 點擊介面上的 **[註冊 TAB]** 切換至註冊表單。
2. 輸入欲註冊之 **使用者名稱**（長度建議 3~20 字元）與 **密碼**。
3. 點擊 **[立即註冊]** 按鈕。
4. 後端將密碼進行 BCrypt 雜湊加密後寫入 `sys_user` 資料表。
5. 註冊成功後，系統自動彈出 SweetAlert2 成功提示並切換回登入頁面。

### 2.2 會員登入與 JWT 憑證
1. 切換至 **[登入 TAB]**，輸入註冊之帳號與密碼。
2. 點擊 **[登入系統]** 按鈕。
3. 驗證成功後，系統將取得 JWT 權杖並安全儲存於瀏覽器 `localStorage`，隨即自動跳轉至主工作台 `/ledger`。

### 2.3 安全登出 (Logout)
- 位於 `/ledger` 工作台右上角之 **[登出]** 按鈕。
- 點擊後將立即清除 `localStorage` 中儲存之 JWT Token 與個人資訊，並導向回 `/login`。

### 3.1 記帳欄位說明與防呆檢核
- **收支類型 (Type)**：可選擇 `支出 (EXPENSE)` 或 `收入 (INCOME)`。
- **交易日期 (Record Date)**：預設帶入當天日期，可點選日曆選擇指定日期。
- **交易分類 (Category)**：下拉選單動態載入系統內建分類與個人自訂分類。
- **金額 (Amount)**：必須為大於 0 之正數 (`amount > 0`)，支援至小數點後兩位。
- **備註說明 (Remark)**：輸入交易摘要說明（如：星巴克咖啡、午餐、九月薪資等）。

### 3.2 快速鍵支援
- 在備註或金額欄位輸入完畢後，直接按下鍵盤 **`Enter`** 鍵即可自動觸發送出記帳，無需動用滑鼠。

## 第 4 章：收支儀表板與即時統計連動

### 4.1 儀表板三大指標定義

| 統計指標卡片 | 計算邏輯 | 顯示樣式規範 |
| :--- | :--- | :--- |
| **本月總收入** | 當月所有 `type = 'INCOME'` 記錄金額加總 | 粗體黑字 / 綠色微標 |
| **本月總支出** | 當月所有 `type = 'EXPENSE'` 記錄金額加總 | 粗體黑字 / 瑞士紅標記 |
| **本月淨結餘** | `本月總收入` − `本月總支出` | 正值呈現 `+ NT$ ...` (正結餘)；負值呈現 `- NT$ ...` (赤字警示) |

### 4.2 即時響應機制 (Real-time Reactive Sync)
在工作台上進行任何**新增記帳**、**修改金額**或**刪除帳目**操作後，前端 Vue 3 會在 API 回傳成功後自動非同步呼叫 `/api/v1/records/summary`，達成**零重新整理**的即時動態更新。

使用者可單獨或組合使用以下 4 大維度過濾帳目：

4. **特定分類 (Category)**：指定僅顯示特定分類之交易紀錄。

## 第 6 章：帳目修改、刪除防呆與資料維護

```
+-------------------------------------------------------------------------------+
|                        流水帳清單與操作列 (Record Table)                      |
+-------------------------------------------------------------------------------+
| 日期       | 類型  | 分類     | 備註說明       | 金額        | 操作            |
|------------|-------|----------|----------------|-------------|-----------------|
| 2026-09-02 | 支出  | 餐飲飲食 | 星巴克特選拿鐵 | - NT$ 120   | [ 編輯 ] [ 刪除 ]|
| 2026-09-02 | 收入  | 薪資收入 | 九月份正職薪資 | + NT$ 45,000| [ 編輯 ] [ 刪除 ]|
+-------------------------------------------------------------------------------+
```

### 6.1 帳目資料修改 (Edit)
1. 於欲修改之記錄右側點擊 **[編輯]** 按鈕。
2. 系統彈出編輯對話框，自動帶入該筆紀錄原始之收支類型、日期、分類、金額與備註。
3. 修改目標欄位（例如：將金額由 120 修改為 150）。
4. 點擊 **[儲存修改]** ➔ 系統送出 `PUT /api/v1/records/{id}` 並同步更新列表與儀表板統計。

### 6.2 帳目資料刪除與防呆 (Delete Safety Check)
1. 點擊記錄右側之 **[刪除]** 按鈕。
2. 系統**不會直接刪除**，而是彈出瑞士風格 SweetAlert2 警示確認視窗：
   > `確定要刪除這筆記帳紀錄嗎？此動作無法復原！`
3. 點選 **[取消]**：終止動作，資料毫髮無傷。
4. 點選 **[確認刪除]**：送出 `DELETE /api/v1/records/{id}` 徹底移除該筆紀錄，並重新計算月度結餘。

## 第 7 章：自訂分類管理與雙層防呆機制

```
+-------------------------------------------------------------------------------+
|                      自訂分類管理對話視窗 (Category Modal)                    |
+-------------------------------------------------------------------------------+
|                                                                               |
|  【分類管理清單】                                                             |
|                                                                               |
|  + 新增自訂分類：[ 分類名稱        ]  類型：[ 支出 ▼ ]  [ + 新增分類 ]        |
|                                                                               |
|  現有分類清單：                                                               |
|  - [系統] 餐飲飲食 (支出)  -->  [ 內建保護 - 不可刪除 ]                       |
|  - [系統] 交通出行 (支出)  -->  [ 內建保護 - 不可刪除 ]                       |
|  - [系統] 薪資收入 (收入)  -->  [ 內建保護 - 不可刪除 ]                       |
|  - [自訂] 毛小孩日常 (支出) -->  [ 刪除分類 ]                                 |
|                                                                               |
+-------------------------------------------------------------------------------+
```

### 7.1 雙層分類架構設計
- **系統內建分類 (`is_system = 1`)**：
  - 如：餐飲飲食、日常用品、交通出行、娛樂休閒、醫療保健、薪資收入、獎金紅利、投資收益等。
  - **保護機制**：所有人共享，系統禁止任何使用者編輯名稱或刪除。
- **使用者自訂分類 (`is_system = 0`)**：
  - 由使用者依個人特殊需求建立（如：毛小孩、模型玩具、外包接案等）。
  - **隔離機制**：只有建立該分類的使用者能看見與使用。

### 7.2 關聯資料刪除防呆 (Data Integrity Guard)
當使用者欲刪除某個自訂分類時，後端將主動檢查 `account_record` 中是否仍有任何記錄引用該分類：
- 若**已有帳目關聯**：拒絕刪除，後端回傳 `409 Conflict`，畫面提示「此分類下已有記帳記錄，請先將關聯帳目移轉或刪除後再進行刪除操作」。
- 若**無任何關聯**：安全刪除該分類。

## 第 8 章：常見問題 (FAQ) 與疑難排解自救指南

### Q1：點擊按鈕時提示「401 Unauthorized」或自動跳回登入頁？
- **原因**：JWT Token 已過期（預設有效期限）或遭手動清除。
- **處理方法**：重新輸入帳號密碼登入即可取得全新有效之 JWT Token。

### Q2：完全在沒有外網 (Air-Gapped) 的環境下，介面會破版嗎？
- **說明**：不會。本專案為 **Strict No-CDN** 架構，所有樣式與 JS 腳本均存放於專案本機 `src/main/resources/static/lib/`，即使拔除網路線也能 100% 完整運作。

### Q3：為什麼記帳時按下送出沒有反應？
- **檢核要點**：
  1. 請檢查「金額」是否填寫大於 0 的正整數或小數。
  2. 請確認是否已選擇「分類」。
  3. 請確認瀏覽器是否已開啟 JavaScript 支援。

### Q4：系統操作時常見 HTTP 狀態碼意義對照表

| 狀態碼 | 意義說明 | 常見發生情境與應對 |
| :--- | :--- | :--- |
| **`200 OK`** | 請求成功 | 正常查詢、修改或刪除完成。 |
| **`201 Created`** | 資源建立成功 | 成功新增一筆流水帳或自訂分類。 |
| **`400 Bad Request`** | 欄位檢核失敗 | 金額未填或為負數、日期格式不合。 |
| **`401 Unauthorized`**| 身分驗證失效 | 未登入或 Token 過期，請重新登入。 |
| **`409 Conflict`** | 衝突/防呆阻擋 | 註冊帳號重複，或刪除已有帳目關聯之分類。 |
| **`500 Server Error`**| 後端伺服器異常 | 請檢查後端 Spring Boot 控制台日誌或資料庫連線。 |
